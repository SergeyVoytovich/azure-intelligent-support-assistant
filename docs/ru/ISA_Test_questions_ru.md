# Azure Intelligent Support Assistant — тестовые вопросы

Этот документ содержит набор тестовых вопросов для проверки ассистента, генерации реалистичной телеметрии и подготовки Live Demo.

---

## 1. Обычные вопросы по базе знаний

Используются для проверки обычной работы RAG и отображения источников.

```text
Какой срок гарантии?

Как долго действует гарантия на ваши продукты?

Есть ли на ваши продукты гарантия?

Что покрывает гарантия?

Как работает доставка?

Сколько обычно занимает доставка?

Есть ли у вас экспресс-доставка?

Какие варианты доставки вы предлагаете?

Можно ли вернуть продукт?

Какова ваша политика возврата?

Как работает возврат денег?

Как я могу получить возврат средств?

Расскажите о вашей компании.

Что это за компания — SVoy Electronics?

Какие продукты или услуги предоставляет ваша компания?
```

## 2. Один смысл, разные формулировки

Полезно для демонстрации Vector Search и Semantic Search.

### Гарантия

```text
Какой срок гарантии?

Как долго я защищён после покупки продукта?

На сколько месяцев распространяется гарантийное покрытие моей покупки?

Если устройство сломается через год, оно всё ещё может быть на гарантии?

Как долго действует гарантийное покрытие продукта?

Есть ли гарантия на продукты, купленные у вашей компании?
```

### Доставка

```text
Сколько занимает доставка?

Когда примерно должен прийти мой заказ?

Каков обычный срок доставки?

Сколько дней мне придётся ждать посылку?

Можно ли доставить мой заказ быстрее?
```

### Возврат

```text
Можно ли вернуть товар?

Что делать, если продукт мне больше не нужен?

Можно ли отправить купленный товар обратно?

Как работает процесс возврата?

Могу ли я получить деньги обратно после возврата продукта?
```

## 3. Разговорные вопросы клиентов

Используются для имитации реальных обращений в поддержку.

```text
Здравствуйте, я недавно купил один из ваших продуктов. Как долго на него действует гарантия?

Я заказал товар несколько дней назад. Когда он должен прийти?

Я получил заказ, но передумал. Можно ли отправить его обратно?

Я хочу вернуть покупку. Что мне нужно сделать?

С моим продуктом возникла проблема. Какие у меня есть варианты по гарантии?

Мне нужен заказ как можно скорее. Есть ли у вас более быстрая доставка?

Можете простыми словами объяснить, как работает возврат денег?

Я думаю о покупке у вас. Какую гарантию вы предоставляете?
```

## 4. Негативный Sentiment

Полезно для проверки Azure AI Language и логики эскалации.

```text
Я очень разочарован своим заказом. Как я могу его вернуть?

Это ужасно раздражает. Мой продукт уже сломался. Что я могу сделать?

Я очень недоволен этой покупкой и хочу вернуть деньги.

Мой заказ всё ещё не пришёл, и это уже начинает сильно раздражать. Какие у меня есть варианты?

Этот продукт перестал работать, и я совсем не доволен. Покрывается ли это гарантией?

Мне надоело ждать. Могу ли я отменить заказ или вернуть его?

Это неприемлемо. Мне нужна помощь с возвратом денег.
```

## 11. Рекомендуемые 5 вопросов для Live Demo

### 1. Базовый RAG

```text
What is the warranty period?
```

### 2. Semantic Search

```text
If my device breaks after a year, could it still be under warranty?
```

### 3. Несколько тем / источников

```text
I want to know about shipping, returns, and warranty before buying.
```

### 4. Негативный Sentiment / Escalation

```text
I'm extremely disappointed. My product is broken and I want my money back. What can I do?
```

### 5. Guardrail / нет релевантной информации

```text
What will the weather be tomorrow?
```

Эти пять вопросов позволяют показать всю цепочку:

```text
Frontend
→ Azure Function
→ Azure AI Language
→ Azure AI Search
→ RAG
→ GPT-4o
→ Sources
→ Escalation
→ Application Insights
→ Azure Dashboard
```
